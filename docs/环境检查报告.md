## 五、需要你手动完成的事项（按顺序）

### ① 【现在做】把 SSH 公钥添加到 GitHub
1. 用记事本打开 `C:\Users\dell\.ssh\id_ed25519.pub`（**注意是 `.pub` 结尾的公钥**），全选复制。
2. 浏览器打开 <https://github.com/settings/keys>（Settings → SSH and GPG keys）。
3. 点 **New SSH key** → Title 填 `Windows-Dell-2026` → Key type 选 **Authentication Key** → 粘贴 → **Add SSH key**。
4. 回到终端验证：
   ```powershell
   ssh -T git@github.com
   ```
   看到 `Hi chensiyuan451-cloud! You've successfully authenticated...` 就成功了。

### ② 【现在做】登录 GitHub CLI
```powershell
& "$env:LOCALAPPDATA\Programs\gh\bin\gh.exe" auth login
```
依次选择：**GitHub.com** → **SSH** → **Login with a web browser** → 复制终端里的一次性代码 → 浏览器粘贴 → 授权。
> ⚠️ 这一步必须你本人操作，我不会替你登录。

### ③ 【需要管理员 + 重启】安装 WSL2 与 Ubuntu 24.04
在**以管理员身份运行**的 PowerShell 或 Windows Terminal 里执行：
```powershell
wsl --install
```
- 这会自动开启「虚拟机平台」「适用于 Linux 的 Windows 子系统」并安装 Ubuntu。
- **执行完必须重启电脑**（提前保存好其他工作）。
- 重启后 Ubuntu 会自己弹窗，让你设置**Linux 用户名和密码**（密码输入时不会显示，正常现象）。
- 装完验证：`wsl -l -v` 应显示 `Ubuntu-24.04  Running  2`。

### ④ 【重启后】安装 Docker Desktop
1. 安装包已下载到 `D:\code\_downloads\DockerDesktopInstaller.exe`，双击安装（需要管理员授权）。
2. 安装时保持 **Use WSL 2 instead of Hyper-V** 勾选。
3. 安装完成后**注销或重启一次**，然后启动 Docker Desktop，等左下角变成绿色 **Engine running**。
4. 验证：`docker --version` 和 `docker compose version` 有输出。

### ⑤ 【可选】安装 Apifox
打开 <https://apifox.com/> 或 <https://www.apifox.cn/>，下载 **Windows 版**安装即可（免费版够用）。
> 备选：接口调试用 Postman 也行，或者直接用 FastAPI 自带的 `/docs` 页面。
