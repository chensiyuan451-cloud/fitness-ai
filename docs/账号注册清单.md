## ⚠️ 安全提醒

1. **API Key 绝不提交到 GitHub**：所有 Key（DeepSeek、阿里云百炼）只写进本地 `.env`。`.gitignore` 必须包含 `.env`、`.env.*`、`*.key`；仓库只提交 `.env.example`（值为空）。这类 Key 是按量计费的支付凭证，**泄露 = 别人花你的钱**。
2. **Key 一旦泄露，删文件没用**：文件推到 GitHub（哪怕是私有仓库、哪怕后来删了 commit）就视为泄露，必须立刻去控制台**吊销旧 Key 并新建**，再检查账单有无异常调用。同理，不要贴到牛客、贴吧、CSDN、微信群里"求帮忙调 bug"。
3. **账号密码独立且唯一**：DeepSeek、阿里云、GitHub、招聘平台不要共用密码（一个站被拖库=全线失守）；GitHub 与邮箱务必开启两步验证（2FA），密码交给密码管理器生成。
4. **简历手机号属于隐私信息**：只投给真实在招岗位。公开版简历 / 公开仓库 / GitHub README / 个人博客里不要把手机号写全。牛客、Boss 等平台的简历可见范围设为"仅投递企业可见"。
5. **不要出借与代认证**：学生认证、优惠券、云服务器账号一律不外借、不代领、不买卖；也不要给任何"代注册/代认证"服务提供学信网验证码、身份证或短信验证码。
